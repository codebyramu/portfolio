VOCARA

VOCARA is a music production tool inspired by digital audio workstations like LMMS and FL Studio. I wanted to solve a problem musicians face while creating beats: creating notes manually feels slow. Humming or singing a melody is much faster and more natural.

I built a feature called Voice-to-MIDI. With VOCARA, users can simply hum or sing into their microphone, and the system converts that audio directly into MIDI notes. Instead of forcing creativity into clicks, VOCARA captures creativity as sound.

Under the hood: I manually calibrated Silero VAD thresholds, RMS gating, and pitch detection pipelines instead of relying on default wrappers.

BloxdioCoderAI

An AI-powered game scripting assistant built for Bloxd.io. Using raw data directly consumed around 60,000 tokens per AI prompt, making it inefficient. So I optimized the entire workflow.

I collected and converted all usable code into structured JSON. Then I built a dual-AI pipeline (RAG):
Key 1 — Refine AI: Understands the request, identifies coordinates/block names, and searches the JSON database.
Key 2 — Code AI: Uses refined prompts and references to generate precise JS code.

ScreamZone

A voice-controlled rhythm game inspired by games like Geometry Dash. Instead of pressing buttons, you control the character using your voice.

The mechanic is simple: High sound = Jump. No sound = No jump. This creates a unique gameplay experience where your voice becomes the controller. The game includes 3 different modes, each designed around sound-based movement mechanics.
